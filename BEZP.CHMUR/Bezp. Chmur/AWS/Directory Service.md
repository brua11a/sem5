**AWS Directory Service for Microsoft Active Directory** (znany również jako **AWS Managed Microsoft AD**) to usługa umożliwiająca uruchamianie i korzystanie z zarządzanego katalogu Active Directory w chmurze AWS. Umożliwia ona integrację aplikacji i zasobów AWS, które wymagają katalogu zgodnego z Active Directory, bez konieczności samodzielnego instalowania i utrzymywania infrastruktury AD.
