AWS Secrets Manager służy do przechowywania *sekretów* - hasła, kluczy API, zmiennych środowiskowych. Pozwala na wygodny i bezpieczny dostęp do nich bez hard-code'owania ani trzymania kopii plików środowiskowych lokalnie u siebie. Tamte rozwiązania są zastępowane zwykły API callem.
