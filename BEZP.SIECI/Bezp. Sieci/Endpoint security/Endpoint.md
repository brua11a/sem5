# W TYM KURSIE POPRZEZ ENDPOINT MAJA NA MYSLI URZĄDZENIE KONCOWE TAKIE JAK KAMERA CZY LAPTOP A NIE ENDPOINT NP. API

Tradycyjnie można je zabezpieczyć antywirusem, [[IPS|host-based IPS]] lub host-based firewallem. Z powodu BYOD i ogólnego trendu zdalnej pracy, zabezpieczenia endpointów nie są takie proste, bo nie można wymagać np. od tego żeby ktoś miał milion dodatkowych software na swoim telefonie, a także może być problem ze spójnością w kontekście np. systemów operacyjnych. 

Ogólnie ochrona endpointów polega dziś na:
- antimalware software
- spam filtering
- blocklisting
- data loss prevention
